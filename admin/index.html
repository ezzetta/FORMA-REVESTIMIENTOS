Editá tus productos, subí fotos y actualizá precios desde Pages CMS, el editor conectado a la web de FORMA. El acceso se realiza con la cuenta de GitHub autorizada para administrar la página.

Abrir administrador de productos ↗

Los cambios se guardan en el catálogo de la web. La publicación puede demorar unos minutos.

Primera activación
  1. Ingresá con la cuenta de GitHub que administra ezzetta/FORMA-REVESTIMIENTOS.
  2. Si te pide instalar Pages CMS, autorizá únicamente el repositorio de FORMA.
  3. Elegí FORMA-REVESTIMIENTOS, rama main, y abrí Productos.
  4. Revisá que GitHub Pages use GitHub Actions como origen de publicación. Esta configuración se hace una sola vez.

Solo las cuentas autorizadas pueden guardar cambios. Este acceso informativo es público; el editor requiere iniciar sesión.

Producto e información

Nombre, categoría, descripción, especificaciones, ambientes, colores, disponibilidad y orden. Ocultá un producto desactivando “Mostrar producto”.

Fotos y galería

Subí, reemplazá y ordená las imágenes. La primera foto es la portada. Describí cada imagen e indicá si es producto, ambientación o información técnica.

Precio y rendimiento

Cargá el importe en pesos y la unidad de venta. Indicá cuántos m² cubre esa unidad. La web calcula el precio por m² y habilita el estimador de cantidades.

Ofertas y descuentos

Activá Oferta e ingresá el descuento porcentual. La web muestra precio anterior, precio final y valor por m² actualizado. Desactivá Oferta para volver al precio de lista.

Sin programar

Buscá el producto, modificá el formulario y guardá. La web reconstruye el catálogo y las fichas automáticamente. Si la publicación falla, el sitio anterior sigue visible.

Control de publicación

Guardá el producto con “Mostrar producto” desactivado mientras lo preparás. Activá esa opción cuando la ficha y las fotos estén listas para aparecer en la web.

Un ejemplo para cargar bien

Una caja a $ 50.000 que cubre 2 m², con 10% de descuento y Oferta activada, muestra $ 45.000 por caja y $ 22.500 por m². Este ejemplo es explicativo y no modifica tus productos.

Usá siempre la misma presentación para precio y rendimiento. Si el precio es por caja, el rendimiento también debe ser por caja. Los precios y las cantidades de stock se actualizan manualmente.
